# Tolerated ROM-shaped hex literals outside src/newton/rom_ver/, one
# per line:
#
#   <file> <normalized-literal> # note
#
# check-rom-addrs.sh flags any in-range literal NOT matched here, and
# fails on stale entries (a listed literal that no longer appears must
# be deleted in the same change). This list was seeded with the
# phase-8 post-migration residue and may only shrink.
#
# Residue categories:
#   [enc]  instruction-encoding masks / patterns whose numeric value
#          happens to land in the ROM range — not addresses at all.
#   [hw]   host-hardware constants (VC mailbox tag IDs, semihosting
#          reason codes, SDHOST fields) — unrelated to the guest ROM.
#   [test] compile-time encoder self-test vectors.
#   [diag] 717006 diagnostic heuristics not yet lifted into rom_ver
#          (candidates for a future migration; deleting the code or
#          migrating the constant shrinks this list).
#   [einstein] Einstein-verbatim model constants in the peripherals
#          layer (which the layering forbids from importing newton) —
#          flash-driver vtable PCs, battery ADC scaling, screen
#          geometry words, kernel-VA window checks.
